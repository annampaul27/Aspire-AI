1. LOCAL ENVIRONMENT SETUP & SERVER STARTUP
================================================================================

Make sure you have your terminal windows open:

TERMINAL 1: BACKEND (FastAPI - Port 8000)
----------------------------------------
1. Navigate to the backend directory:
   cd backend
2. Activate Python virtual environment:
   Windows: .\venv\Scripts\activate
   Linux/macOS: source venv/bin/activate
3. Start the FastAPI development server:
   python run.py
4. Verify backend health:
   Open http://localhost:8000/health in browser (Should return: {"status": "healthy"})
   Interactive Swagger docs: http://localhost:8000/docs

TERMINAL 2: FRONTEND (Next.js 15 - Port 3000)
---------------------------------------------
1. Navigate to the frontend directory:
   cd frontend
2. Start the Next.js development server:
   npm run dev
3. Open http://localhost:3000 in your browser.

TERMINAL 3: STANDALONE STREAMLIT AI INTERVIEW COACH (Port 8501)
--------------------------------------------------------------
* Note: For standalone academic project demonstration or viva evaluation:
1. Navigate to the interview coach directory:
   cd services/interview_coach
2. Start the Streamlit application:
   streamlit run streamlit_app.py --server.port=8501
   (Or on Windows, simply double-click run_streamlit.bat)
3. Open http://localhost:8501 in your browser.
